# Maquettes

`boards/*.html` : chaque écran de la direction V4, en HTML statique. Ouvrir dans un navigateur (les polices viennent de Google Fonts, les textures de `../../public/textures`).

- Préfixe `M` = mobile (390 px de large). Sans préfixe = desktop (1440 px).
- Les styles sont inline : c'est une référence de valeurs (tailles, couleurs, ombres, flous, rayons), pas du code à reprendre tel quel. L'app utilise les tokens et composants de `docs/04-design-system.md`.
- Les rendus correspondants sont dans `docs/screens/*.jpg` (les écrans très hauts sont aussi découpés en `-1`, `-2`…).
- Les photos d'articles sont des fonds « studio » vides : dans l'app, ce sont les vraies photos.

Le canvas de design complet (toutes les versions, y compris les directions abandonnées) reste disponible sur claude.ai.
